# 🚕 Taxi Data Analysis using Python

## 📌 Project Overview


In this assignment, I worked with the **Taxi dataset** from Seaborn and performed data cleaning, analysis, and visualization using Python.

The main goal of this project is to understand **taxi fares, trip distances, payment methods, tips, and pickup boroughs**.

## 🧹 Data Cleaning

The following data cleaning steps were performed:

* Checked for missing values
* Identified columns containing missing data
* Filled missing numerical values using the **median**
* Filled missing categorical values using the **mode**
* Removed rows with missing values from critical columns
* Converted pickup and dropoff columns to datetime format

## 📊 Data Visualizations

### Matplotlib / Pandas

1. **Line Chart** – Fare over time
2. **Bar Chart** – Total fare by pickup borough
3. **Pie Chart** – Trips by payment method
4. **Histogram** – Distribution of trip distance
5. **Box Plot** – Tip distribution by pickup borough

### Seaborn

6. **Count Plot** – Number of trips by pickup borough
7. **Scatter Plot** – Relationship between distance and fare
8. **Heatmap** – Correlation between numerical variables
9. **Pair Plot** – Relationships between distance, fare, tip, and total
10. **Violin Plot** – Fare distribution by payment method
